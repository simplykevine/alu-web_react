# Webpack Module

## Learning Objectives
Master modern JavaScript bundling and build optimization with Webpack:
- Configure Webpack for development and production
- Implement asset loading strategies (CSS, images, fonts)
- Optimize bundles for performance
- Set up development servers with hot reloading
- Understand module federation concepts

## Tasks Overview

### Task 0: Basic Webpack Setup
- Initial Webpack configuration
- Entry points and output configuration
- Basic JavaScript bundling

### Task 1: Development vs Production
- Environment-specific configurations
- Development server setup
- Production optimizations

### Task 2: Asset Loading
- CSS loading with style-loader and css-loader
- Image and font handling
- File optimization strategies

### Task 3: Advanced Configuration
- Module federation concepts
- Code splitting strategies
- Performance optimization

## Quick Start

### Running Any Task
```bash
cd task_<number>
npm install
npm run build        # Production build
npm run start-dev    # Development server (where available)
```

### Key Webpack Features
- Bundle optimization and minification
- Asset management and loading
- Development server with hot reloading
- Source map generation for debugging
- Module resolution and aliasing
